# Custom `@delon/form` widgets

Define custom widgets under the `widgets` directory and register them here.

> `@delon/form` already ships every NG-ZORRO data-entry widget. Additional third-party widgets can
> be copied from [widgets-third](https://github.com/ng-alain/delon/tree/master/packages/form/widgets-third)
> into `widgets` and registered the same way.
